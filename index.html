Kiểm tra nguồn dữ liệu xổ số

Trang thử nghiệm cho XSMB, XSMT, XSMN và Vietlott. GitHub Actions tự kiểm tra nguồn và cập nhật báo cáo; trang này tự đọc báo cáo mới nhất khi được mở trên GitHub Pages.

Cách hoạt động: GitHub Actions tự kiểm tra nguồn theo lịch và ghi báo cáo vào reports/source-status.json. Khi trang được xuất bản bằng GitHub Pages, báo cáo sẽ tự tải khi mở trang và tự kiểm tra lại mỗi 5 phút. Nếu mở trực tiếp bằng file trên máy tính, trình duyệt có thể chặn đọc JSON; khi đó hãy dùng URL GitHub Pages hoặc chọn file JSON thủ công.

1. Tự động kiểm tra

Sau khi cài đặt một lần, GitHub Actions tự chạy mỗi 6 giờ và bạn cũng có thể chạy ngay khi cần. Báo cáo được ghi trực tiếp vào repository; không cần tải artifact.

Tạo repository

Chạy workflow một lần thủ công để thử ngay. Lịch tự chạy tiếp tục hoạt động khi bạn đóng máy tính.

Xuất bản trang index

Trong repository, vào Settings → Pages, chọn Deploy from a branch, branch main, folder /(root), rồi Save. Mở URL GitHub Pages để báo cáo tự tải.

2. Báo cáo tự cập nhật

Trang sẽ tự tải reports/source-status.json từ cùng website. Bạn không cần tải báo cáo xuống máy.
