Kiểm tra nguồn dữ liệu xổ số

Trang thử nghiệm cho XSMB, XSMT, XSMN và Vietlott. Chạy bộ kiểm tra bằng GitHub Actions, sau đó tải báo cáo JSON vào đây để xem kết quả.

Lưu ý: Trang này không tự xác minh kết quả trúng thưởng trong trình duyệt. Việc kiểm tra nguồn cần chạy bằng Python trên GitHub Actions vì nhiều website chặn yêu cầu từ trình duyệt (CORS). Bảng bên dưới chỉ hiện báo cáo khi bạn tải báo cáo JSON từ lần chạy thực tế.

1. Chạy kiểm tra nguồn

Đưa thư mục dự án lên GitHub trước. Mỗi lần muốn kiểm tra, mở workflow trong tab Actions và chạy thủ công.

  1. Mở repository GitHub của bạn.
  2. Chọn Actions → Check lottery data sources.
  3. Bấm Run workflow và chờ hoàn tất.
  4. Mở lần chạy vừa xong, tải artifact appnho-lottery-source-report.
  5. Giải nén artifact để lấy source-status.json.
Tạo repository

Nút mở Actions cần tên repository đầy đủ, theo dạng tài-khoản/tên-repo.

2. Xem báo cáo

Chọn file source-status.json được tạo bởi workflow. Trang sẽ đọc file ngay trên máy của bạn, không tải lên máy chủ.
